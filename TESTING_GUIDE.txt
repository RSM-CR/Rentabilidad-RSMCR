Antes de ejecutar cualquiera de estos comandos, entra al directorio del backend:

cd "C:\Users\RicardoCorredorMedin\Documents\GitHub\main\backend"

---------------------------------------------------------------------
1) Hacer login
---------------------------------------------------------------------

$login = Invoke-RestMethod `
  -Uri "http://localhost:3000/api/login" `
  -Method Post `
  -ContentType "application/json" `
  -Body (@{
      email = "admin@tuempresa.com"
      password = "TuPassword123"
  } | ConvertTo-Json)

$token = $login.token

---------------------------------------------------------------------
2) Mostrar la cuenta autenticada
---------------------------------------------------------------------

Invoke-RestMethod `
  -Uri "http://localhost:3000/api/me" `
  -Method Get `
  -Headers @{ Authorization = "Bearer $token" }

---------------------------------------------------------------------
3) Crear usuario
---------------------------------------------------------------------

$body = @{
  nombre = "Ana"
  email = "ana@empresa.com"
  password = "Ana123!Password"
  role = "Analista"
  filter = "Finanzas corporativas"
} | ConvertTo-Json

Invoke-RestMethod `
  -Uri "http://localhost:3000/api/users" `
  -Method Post `
  -ContentType "application/json" `
  -Headers @{ Authorization = "Bearer $token" } `
  -Body $body

---------------------------------------------------------------------
4) Listar usuarios
---------------------------------------------------------------------

Invoke-RestMethod `
  -Uri "http://localhost:3000/api/users" `
  -Method Get `
  -Headers @{ Authorization = "Bearer $token" }

---------------------------------------------------------------------
5) Eliminar usuario
---------------------------------------------------------------------

$email = "ana@empresa.com"

Invoke-RestMethod `
  -Uri "http://localhost:3000/api/users/$email" `
  -Method Delete `
  -Headers @{ Authorization = "Bearer $token" }

---------------------------------------------------------------------
6) Subir archivos para análisis
---------------------------------------------------------------------

# Ruta completa del archivo 1
$file1 = "C:\Users\RicardoCorredorMedin\Documents\GitHub\main\backend\test-files\Facturas-prueba1.xlsx"

# Ruta completa del archivo 2
$file2 = "C:\Users\RicardoCorredorMedin\Documents\GitHub\main\backend\test-files\Staff-Time-Summary-Report-prueba (1).xlsx"

curl.exe -X POST "http://localhost:3000/api/analysis/upload" `
  -H "Authorization: Bearer $token" `
  -F "file1=@$file1" `
  -F "file2=@$file2"

---------------------------------------------------------------------
7) Comparar archivos de análisis
---------------------------------------------------------------------

curl.exe -X POST "http://localhost:3000/api/analysis/compare" `
  -H "Authorization: Bearer $token" `
  -F "file1=@$file1" `
  -F "file2=@$file2"

---------------------------------------------------------------------
8) Alias legado por compatibilidad
---------------------------------------------------------------------

curl.exe -X POST "http://localhost:3000/api/upload-two" `
  -H "Authorization: Bearer $token" `
  -F "file1=@$file1" `
  -F "file2=@$file2"

---------------------------------------------------------------------
Notas importantes:
- Usa la ruta real de tu laptop si la carpeta del proyecto está en otra ubicación.
- Si el backend se levanta en otro puerto, cambia http://localhost:3000 por ese puerto.
- Si tu usuario admin real en la base de datos tiene otros datos, usa esos valores en el login.
- Las rutas de archivos deben apuntar a archivos reales que existan dentro de backend\test-files.
